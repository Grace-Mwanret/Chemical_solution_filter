# About
The program takes pH range from the user, and returns compounds that pass the filtering condition.

# How to run it
It is a simple python project so it can be run on any code editor just make sure a working python version is installed on it.

# What it does
It takes pH ranges from the user and returns compounds that fall within that range. It is able to do that because of the filtering condition set in place.
The pH scale runs from 0 to 14 — values below 7 are acidic, 7 is neutral, and values above 7 are alkaline.

# What I learned
I learned how to use these concepts: functions, filter function, lambda function, lists, tuples(used to group the compounds with their pH value), loops, unpacking(used to extract each value from the tuple for display).

# Example output
Water: pH 7
Black coffee: pH 5
